Corsano CardioWatch recognizes a VF arrest in post-processing

Radboudumc DETECT-3 case: a 64-year-old's VF arrest while cycling was ended by his ICD; the CardioWatch PPG algorithm later detected pulselessness at 09:50:17 and the fall; no live alert was sent.

ⓘ

AI system

System

Corsano CardioWatch 287-2 with the DETECT photoplethysmography cardiac-arrest detection and accelerometry fall-detection algorithms

Model

DETECT, a rule-based algorithm that detects absent pulsations.

Release

Exact release not established.

Application developer

DETECT program, Radboud University Medical Center, with Corsano Health, The Hague (device and algorithm processing)

Role

Not assessed

Configuration

Researchers applied DETECT after the event to data from a CardioWatch 287-2. The algorithm did not run live or send an alert.

Not assessed

Workflow

Continuous wristband wear with 32 Hz photoplethysmography and accelerometry uploaded to a study cloud. A shockable arrest with clear loss of pulsations during cycling, in a patient whose ICD provided the reference and the rescue. Blinded after-the-fact processing by the developers' data scientist.

Human oversight

Not assessed

Relation to AI

general benefit

AI contribution

The algorithm was run afterwards on exported data by a blinded Corsano data scientist. It correctly flagged the loss of pulse and the fall. It was not running live and sent no alert. The ICD shock is what restored circulation. The developers' own papers are the only full sources. They describe a rule-based detector of absent pulsations by signal amplitude and waveform morphology rather than a machine-learning model.

Follow-up

Conditions for replication

Adequate photoplethysmography quality during motion (the authors note it is typically disturbed by motion). A live implementation with acceptable false-positive rates, which DETECT-3 is still measuring. An alerting chain to emergency services, which does not yet exist for this device.

Replication attempts

2 follow-up entries. Benefit recurred: 2.

Later findings

24 July 2026. The same group's later prospective validation in ICU patients with non-shockable arrest after withdrawal of life-sustaining treatment reported 100% sensitivity in the 23-patient test set with one false positive, and DETECT-1b (April 2026) externally validated the algorithm in 50 induced shockable arrests; no live alerting has been reported.
