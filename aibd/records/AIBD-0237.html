curl merges about 50 bugfixes from ZeroPath-assisted scans

In Sept 2025 curl received hundreds of candidate issues found mainly with the ZeroPath AI analyzer by Joshua Rogers; maintainer Daniel Stenberg merged about 50 bugfixes from the first list.

ⓘ

What happened

The reports arrived from mid-September 2025. Stenberg writes that a security report received on 16 September accurately identified a possible stack-based buffer overflow in curl's Kerberos FTP code. It was not turned into a CVE only because the code could not be reached. The project then removed krb5-ftp support. The reporter, Joshua Rogers, then forwarded a large list of further potential issues found mostly with ZeroPath, an AI-powered code analyzer. That produced over two hundred possible problems despite curl's existing compilers, static analyzers and fuzzing. From the initial list about 50 separately identifiable bugfixes were merged. Second and third lists of 47 and 158 items followed. Stenberg told The Register that about 50 bugfixes based on Rogers' reports had been merged.

Rogers' retrospective states that about 98% of the curl bugs reported and fixed were discovered by ZeroPath. It puts the running total of fixed bugs around 150.

Purpose. AI-powered static analysis of source code to find vulnerabilities and bugs.

AI’s contribution

The maintainer confirms the reports' quality and the merged fixes. He notes he does not know the exact split between tool and human. Rogers attributes ~98% of the fixed curl bugs to ZeroPath. Both the deployer and the confirming maintainer are independent of the vendor.

Beneficiaries

  • an organization

    About 50 merged bugfixes from the first list, a potential overflow identified and unused code removed, per the curl maintainer.

  • society

    curl is widely deployed, but no user-facing incident was averted. The merged fixes are described as mostly small mistakes.

Since then

Further evidence

Setting. A large, mature C codebase already covered by conventional analyzers and fuzzing. An expert researcher filtering scanner output before reporting. Maintainers willing to work through long candidate lists.

Conditions. Human triage to remove false positives. Maintainer capacity to review hundreds of items.
