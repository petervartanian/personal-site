OpenAI's o3 flags an unknown flaw in the Linux kernel's file server

OpenAI's o3, which the researcher Sean Heelan ran through the plain application programming interface, flagged a previously unknown use-after-free in the Linux kernel's SMB server, now CVE-2025-37899.

    Heelan gave the kernel project a report and a fix, and its maintainers committed the fix on 25 April 2025.

What happened

Sean Heelan is an independent vulnerability researcher who was auditing ksmbd, the Linux kernel's in-kernel server for the SMB3 file-sharing protocol. He used a known bug (CVE-2025-37778) to benchmark OpenAI's o3 through the plain application programming interface, with no scaffolding, agents or tools. Given about 12,000 lines covering all SMB command handlers, o3 reported a previously unknown use-after-free in the handler for the SMB “logoff” command. In that flaw, sess->user can be freed while another connection bound to the same session still uses it. Heelan wrote the fix on 21 April 2025. The SMB maintainer Steve French committed it to the kernel on 25 April 2025 with the acknowledgment of the ksmbd maintainer, Namjae Jeon. The fix reached the 6.12 and 6.14 branches in April and May 2025. The Linux kernel's CVE Numbering Authority published CVE-2025-37899 on 20 May 2025. Heelan's write-up followed on 22 May 2025. He calls it, to his knowledge, the first public case of a large language model finding a vulnerability of that nature. Linuxiac reported on 29 May 2025 that the upstream response was fast and that patches had been merged for every maintained branch. The fix reached the 6.1 and 6.6 longterm branches later, on 6 December 2025. The CVE record now describes the fix (“ksmbd: fix use-after-free in session logoff”) with commits in five stable branches, and it lists fixed versions 6.1.159 and 6.6.119.

Details

AI system

Model

O3.

Role

The model analyzed source code and identified a possible vulnerability for a researcher to verify.

Configuration

Heelan used o3 through the plain API with about 12,000 lines of SMB handler code and no agents, tools or additional scaffolding.

Inputs and outputs

The model received source code and returned a suspected use-after-free involving a session user during logoff.

Workflow

A code slice under roughly 10k-12k lines chosen by an expert. Repeated model runs with reports triaged by a human. A maintainer workflow that accepts and patches reports quickly.

Human oversight

Heelan selected the code, verified the finding and managed disclosure; kernel maintainers applied the fix.

Benefits

Duration

The fix entered mainline on 25 April 2025 and the 6.12 and 6.14 branches in April and May 2025. Backports to the 6.1 and 6.6 longterm branches followed on 6 December 2025, and the CVE record now lists fixed versions 6.1.159 and 6.6.119. [1] [2] [3] [4] [5]

Follow-up

Conditions for replication

Expert curation of context and validation of candidate bugs. Tolerance for false positives across runs.
