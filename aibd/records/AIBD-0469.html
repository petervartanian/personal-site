What happened

Addis Ababa Science and Technology University in Ethiopia proposes an edge-and-cloud system that uses AI to detect intrusions into Internet of Things networks. In an International Telecommunication Union (ITU) report that is current as of June 2025, the authors report that they trained models on a cleaned version of the public CICIoT2023 dataset. They ran only a simulated edge deployment, and a lab test in a smart home network is still planned. They report no accuracy figures, and detection performance and security benefits remain unreported. The account lists the code repository as coming soon. No paper, code release or deployment report from the team appeared after June 2025.
