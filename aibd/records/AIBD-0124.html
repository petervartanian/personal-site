Code Intelligence's Spark finds a heap use-after-free in wolfSSL

Code Intelligence's Spark, an AI agent that writes and runs fuzz tests, found a heap use-after-free in wolfSSL in late October 2024; wolfSSL shipped the fix in 5.7.6 on 31 December 2024.

  • 2 an organization

    wolfSSL received a reproducible report of a heap use-after-free in a path that parses private keys. It merged the fix within days, in pull request 8139 on 1 November 2024, and shipped it in 5.7.6 on 31 December 2024. The maintainers listed it among bug fixes, and the release's Vulnerabilities section does not include it. wolfSSL's vulnerabilities page lists no Common Vulnerabilities and Exposures identifier for it. The vendor itself says that the exploit conditions “don't seem easy to meet”, so the benefit is material and bounded.

What happened

Spark is the AI test agent in Code Intelligence GmbH's CI Fuzz product. Its final beta test in late October 2024 ran it on wolfSSL, an open-source cryptography library for embedded and Internet of Things devices. By the vendor's account, after one command the agent chose the target, generated and ran a fuzz test and exposed a heap use-after-free in pem_read_bio_key(). There a BIO write-back could reallocate a buffer that a pointer still referenced. The vendor reported it to wolfSSL, which merged a fix in pull request 8139 on 1 November 2024. The fix shipped in release 5.7.6 on 31 December 2024, and the release notes credit “Peter”. On 3 January 2025 the vendor's engineer Peter Samarin described the find on the company blog.

Details

AI system

Inputs and outputs

Spark generated and ran fuzz tests for wolfSSL and produced a crash that exposed an invalid memory read.

Workflow

WolfSSL's source tree (before 5.7.6) set up as a CI Fuzz project by the vendor. A single “cifuzz spark” command, after which the agent chose pem read bio key() as a target and generated and ran a fuzz test. A sanitizer-detectable heap use-after-free in the BIO write-back path of pem read bio key() that a generated input could trigger. A maintainer team that tracked the report as ZD#18875 and merged a fix within three days of the discovery.

Human oversight

Engineers evaluated the crash, and wolfSSL maintainers reviewed and merged the repair.

Relation to AI

On the vendor's account, Spark selected the target, generated the fuzz test and ran it after a single “cifuzz spark” command. One manual step confirmed that the finding was real and exploitable under narrow conditions. WolfSSL's pull request and release notes confirm the bug, its location in pem read bio key(), the timing and the reporter's first name. They mention neither AI nor Code Intelligence. The autonomous discovery therefore rests on the vendor's statements, repeated by QA Financial and SC Media, not on an independent test.
