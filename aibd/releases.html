Dataset editions

Each edition preserves the cases and assessments as published. Its download contains JSON and CSV files, the field definitions, and a manifest of file checksums.

An edition’s identifier is the SHA-256 digest of those file checksums, written as JSON with sorted keys. The checksum of the ZIP file itself is a separate value.
