# Definition evidence recovered from shared tracker files

- **Potential causes:** the older RCA prompt requires six categories, at most three cause/explanation pairs each, and N/A placeholders for empty categories. The deployed source documents the same six-category structure. The new profile excludes placeholders, describes annotations, and does not establish causation.
- **Behavior:** the older classification prompt defines Agent, Autonomous, Assistant, Collaborator, Tool, Hybrid, Swarm and Orchestrator. Tool means a specific function using direct input without retained context, with deterministic outputs. The September export includes Multi-agent and unknown; these do not match the old eight-label vocabulary. A current versioned rubric is still needed. Finding an old rubric is not proof it governs the new classifier.
- **National security:** the prompt requires five scores from 1 to 5, overall equal to the maximum, conservative assessments based on reported evidence, and separate autonomy/imminence/novelty labels. The supplied export's overall scores match the maximum of its five axes. A separate earlier preliminary review reports national-security ratings on eight consensus cases. It is not representative current-pipeline validation.
- **Harm scales:** the recovered rubric defines the original ten dimensions at 1–5, including no harm within score 1. It supplies no definition for zero and no thresholds for the three added harm dimensions. Those remain specific exporter/rubric-owner questions.
- **People counts:** the historical classification prompt permits best estimates even for fields labeled reported. This strengthens the existing caution against treating these values as confirmed counts of distinct people. Applicability to the current prompt requires version confirmation.

Sources and content hashes are in the private SOURCE_MANIFEST.json. The paired pilot reference contains no national-security labels; its 160 rows cover ten incidents and five other taxonomies. Current-label agreement is a case diagnostic, not proof of global accuracy or a confirmed holdout.
