## What is working

The offline pipeline snapshots a CSV, validates the schema and IDs, calculates exploratory tables and sensitivity checks, audits preserved claims, emits reports and machine-readable evidence, and records code/config/prompt hashes. The default cadence is monthly; fortnightly uses the same calculations. A CLI evidence command exposes the exact incident records behind a finding.

## Limits

This is a single-export analysis, not a reconstructed history of monthly exports; a comparison tool exists but no earlier real export does. Representative controls, charts and incident details were exercised in the in-app browser and native Safari on September 27–28, 2026. Exact coverage and exclusions are recorded in review/browser/BROWSER_CHECKS.md. The live mirror differs from the supplied CSV even when both contain 1,698 records; a compatible chart configuration does not guarantee identical live figures. C04 exposes nine grouping dimensions plus None, while C03 exposes thirteen dimensions. Full report-level corroboration, the meaning of zero-coded severity cells, and independent validation of classification accuracy remain open. LLM generation/review was session-assisted; the provider adapter exists but has not been executed against a live API. Publication decisions remain with humans.
